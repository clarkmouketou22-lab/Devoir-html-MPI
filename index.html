1. Définition du DevOps

Le DevOps est une culture et un ensemble de pratiques qui visent à unir le développement logiciel (Dev) et l'exploitation informatique (Ops). L'objectif est d'automatiser et d'accélérer la livraison des applications pour avoir plus de qualité et de rapidité.

2. Commandes Git utilisées

  • git add . : Prépare tous les fichiers pour le commit
  • git commit -m "message" : Enregistre les modifications localement
  • git push : Envoie les modifications sur GitHub
